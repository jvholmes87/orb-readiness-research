# Sensitive Information and Security Reporting

This repository is intended for public research-design and source-verification material only.

## Do not open a public issue for sensitive material

If you believe the repository exposes non-public correspondence, personal information, proprietary firm data, contract identifiers, credentials, private links, controlled information, or another sensitive artifact, do not reproduce that material in a public issue or pull request.

Use GitHub's private vulnerability-reporting feature if it is enabled. If it is not available, contact the repository owner through a non-public contact method listed on the owner's GitHub profile and provide only the minimum information necessary to identify the affected file or commit.

## Scope

Examples of information that should not appear here include:

- Participant or firm identities unless explicitly approved for publication
- Proprietary processes, buyer-sensitive records, private assessments, or source correspondence
- Personal phone numbers, private email addresses, addresses, or internal Drive links
- Credentials, API keys, tokens, passwords, or unpublished datasets
- Controlled, classified, export-controlled, or otherwise restricted information

The repository owner may remove or rewrite affected Git history when necessary to protect sensitive information.
